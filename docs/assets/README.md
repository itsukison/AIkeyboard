# Docs Assets

Reference images that are not compiled into the app live here.

- `marketing/` — generated or exploratory product visuals for campaigns, store work, or demos.
- `screenshots/debug/` — visual QA and debugging captures.
- `screenshots/manual/` — manual product screenshots.
- `screenshots/punctuation/` — punctuation bug reference captures.

Runtime app images belong in `iOS/Container/Resources/Images/`, not here.
