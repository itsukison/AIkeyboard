# App Store Release Note — 敬語ボタン 1.0.18 (build 21)

## 日本語（App Store 本体）

### フリック入力も、触れた瞬間に文字が出ます
- かなフリックで、キーに触れた瞬間に文字が入力され、指を動かすとその場で文字が入れ替わります。指を離すのを待たずに次のキーを打てる、純正キーボードと同じ挙動になりました。
- 同じキーを続けて押す切り替え（あ→い→う）も、触れた瞬間に進みます。
- キーに触れると、押しているキーが大きく表示されるようになりました。
- 上・右へのフリックが反応しにくく、中央の文字が入力されてしまうことがある問題を修正しました。

### AIの書き換え候補が、できた順に表示されるように
- これまでは3件そろうまでお待ちいただいていましたが、1件できるごとに順にカードが表示されます。結果を見始めるまでの時間が短くなりました。
- iOS 26で、候補カードをタップしても反応しないことがある問題を修正しました。

### iPadのキーボードを純正の並びに調整
- ローマ字キーボードの配列を、純正の日本語iPadキーボードと並べて計測し直しました。ホーム行のずらし配置、行ごとのキーの幅と高さ、「.?123」や改行キーの表記など、見た目と使い心地を純正に合わせています。

### 初回設定で、あなた専用のAIボタンを作成
- 用途を選んだあと、いくつかの質問にタップで答えるだけで、その用途に合わせたAIボタンを自動で作成します。作成したボタンは、その場で練習できます。

### その他の改善
- 「触覚フィードバック」の設定を、キーボード設定の中に移動しました。
- 初回設定のキーボード切り替え練習が、正しく完了できないことがある問題を修正しました。
- いくつかの不具合を修正し、軽微な改善を行いました。

ご意見・ご要望はアプリ内の「フィードバック」からお送りください。日本語でのご入力体験、引き続きよろしくお願いいたします。

## English (App Store / secondary localization)

### Flick input now lands the instant you touch
- On the kana flick keyboard, the character is inserted on touch-down and swaps in place as your finger moves between directions. You no longer wait for the lift before pressing the next key — just like the system keyboard.
- Tap-cycling the same key (あ→い→う) also advances on touch-down.
- The key you're pressing now enlarges the moment you touch it.
- Fixed upward and rightward flicks sometimes failing to register, which silently typed the centre character instead.

### AI rewrite candidates now appear as they're ready
- Instead of waiting for all three candidates, each card shows up the moment it's generated, so you can start reading sooner.
- Fixed an issue on iOS 26 where tapping a candidate card sometimes did nothing.

### The iPad keyboard now matches the native layout
- Re-measured the romaji keyboard against the native Japanese iPad keyboard: the staggered home row, per-row key widths and heights, and the ".?123" and return-key labels now follow the system layout.

### Build your own AI button during setup
- After picking your goal, answer a few questions with taps and an AI button tailored to it is generated for you — ready to practise with right there.

### Other improvements
- Moved the haptic feedback setting into Keyboard Settings.
- Fixed an issue where the keyboard-switching exercise in the first-time setup sometimes couldn't be completed.
- Misc bug fixes and minor improvements.

We'd love your feedback via the in-app Feedback screen. Thank you for typing with 敬語ボタン.

## 简体中文 (App Store / secondary localization)

### 假名滑动输入，触碰即出字
- 在假名滑动键盘中，手指碰到按键的瞬间即输入文字，移动手指时文字会原地替换。无需等待抬手即可按下一个键，与系统键盘行为一致。
- 连续按同一个键的循环切换（あ→い→う）也在触碰瞬间生效。
- 触碰按键时，会放大显示所按的按键。
- 修复了向上、向右滑动有时无响应、误输入中央字符的问题。

### AI 改写候选现在生成一个显示一个
- 不再等待三条候选全部完成，每条生成后即刻显示，可以更早开始查看。
- 修复了 iOS 26 上点击候选卡片有时无响应的问题。

### iPad 键盘对齐原生布局
- 罗马字键盘按照原生日语 iPad 键盘重新测量调整：主键行的错位排列、各行按键的宽度和高度，以及「.?123」与回车键的显示，均与系统键盘一致。

### 在初始设置中创建你的专属 AI 按钮
- 选择用途后，只需点选回答几个问题，即可自动生成贴合该用途的 AI 按钮，并可当场练习使用。

### 其他改进
- 「触觉反馈」设置已移至键盘设置内。
- 修复了首次设置中的键盘切换练习有时无法正常完成的问题。
- 修复了若干问题，并做了小幅改进。

欢迎使用应用内"反馈"告诉我们你的想法。感谢您使用 敬語ボタン。
